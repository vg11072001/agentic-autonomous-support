# Return Follow-Up for Damaged Items

## When this article applies

Use this article when a customer has already returned, or is following up on, an item that was damaged or defective.

Typical requests include:

- "I want to follow up on my return order, the item was damaged."
- "I returned the damaged item but have not heard back."
- "What is happening with my damaged-item return?"
- "The item was damaged and I already sent it back."

## Required checks

Ask for or retrieve the order ID if it is not already available.

Then determine:

1. Whether the item was reported as damaged.
2. Whether the required photo evidence was submitted.
3. Whether the return was received by the warehouse.
4. Whether warehouse inspection is complete.
5. Whether the refund has already been issued.
6. If issued, whether 5–7 business days have passed since inspection.

## Policy references

- `POL-DMG-002` governs damaged/wrong-item claim requirements and review.
- `POL-RET-002` governs return eligibility and the refund timeline after warehouse inspection.
- `POL-REF-002` governs refund approval/review rules.

## Important distinction

A damaged-item claim and a refund-status question are related but not identical.

Do not answer "your refund is late" merely because the customer says they returned a damaged item. First determine whether the warehouse received and inspected the return.

## Escalation

If the return was received and inspection is complete but the refund has not arrived after the applicable 5–7 business-day period, route the case for refund-status investigation.

If manual review is required, do not promise automatic approval.
