# Order Cancellation Policy

## Purpose
This policy defines when a customer can cancel an order and what happens when cancellation is no longer available.

## Eligibility
- An order can be cancelled free of charge within **1 hour of placement**, provided warehouse processing has not started.
- If warehouse processing has already started, cancellation is not available through customer support.
- Once cancellation is unavailable, the customer should be guided to the applicable return process after delivery.

## Required information
The support assistant should request the **order ID** before attempting an order-specific cancellation.

## Cancellation workflow
1. Ask for the order ID if it is not already available.
2. Check the current order status and whether warehouse processing has started.
3. If the order is within the 1-hour cancellation window and processing has not started, the order may be cancelled.
4. If processing has started, explain that cancellation is no longer available and provide return guidance instead.

## Important distinction
A customer saying "I just placed it by mistake" does **not** by itself guarantee cancellation. Eligibility depends on the order's age and processing status.

## Example customer requests
- "I just placed my order by mistake. Can you cancel it?"
- "I ordered the wrong thing five minutes ago."
- "Please cancel order ORD-12345."
- "I changed my mind, can you stop the order?"
