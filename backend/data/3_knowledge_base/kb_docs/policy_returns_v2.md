# Returns and Refund Timeline Policy

## Standard return window
Items may be returned within **30 days of delivery** when they are unused and in original packaging.

## Electronics
Electronics have a **15-day return window** because of manufacturer restocking terms.

## Return shipping
- Defective or incorrect items qualify for free return shipping.
- Customer-initiated change-of-mind returns incur a **$5.99 shipping deduction** from the refund.

## Refund after return
After the returned item passes warehouse inspection, the refund is issued to the original payment method within **5–7 business days**.

## Important distinction
A return being eligible does not mean the refund is instantaneous. The return must pass warehouse inspection before the 5–7 business-day refund timeline begins.

## Examples
- "I don't want the item anymore." → Check return eligibility and change-of-mind shipping deduction.
- "You sent me the wrong item." → Defective/incorrect return shipping is free; refund eligibility is governed by the applicable refund rules.
- "I returned it already. Where is my money?" → Check warehouse inspection status and the 5–7 business-day timeline.
