Aurora Support

Autonomous support with agent memory on CockroachDB.

More abstract/enterprise-sounding — memory and context persisting seamlessly across turns, agents, and time. Good if you want something that sounds like a platform/product rather than a single feature. One cluster holds the whole memory layer — synthesized case state, vector retrieval, cross-customer similar cases, the guardrail verdict cache, versioned skills, and a tamper-evident audit chain.

Signal-routed memory

Signals (not a segment) pick which tools fire: KB, this customer's history, similar resolved cases, cohort.

Input + output firewall

A semantic firewall screens the request; a two-tier guardrail checks the reply and red-teams autonomous money actions.

Skills as memory

The planner selects a versioned resolution playbook; new ones are drafted from recurring escalations and human-reviewed.

Tamper-evident audit

Every decision is hash-chained in CockroachDB; altering any record breaks the chain, and the console verifies it live.

Simulation flywheel

Generate realistic cohort scenarios, run them through the live agent graph, and compare across prompt, model, and flow versions to catch regressions before deployment.

Escalations

Escalated cases are reviewed by human agents for resolution. Also highlighted knowledge bases gaps.

Built on CockroachDB (memory + vectors + audit) and AWS Bedrock. The Memory Inspector is the primary demo surface.
